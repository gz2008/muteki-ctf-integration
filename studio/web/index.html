 QUICK START

          
CTF Studio 使用指南

        

        
      


      

        

          1
          

            把题目交给它
            
在“开始解题”里粘贴题面；有 URL 就填到“高级 → 题目 URL”；附件直接拖进输入框。Ctrl+Enter 可以直接派发。

          

        

        

          2
          

            选一个模式
            
本地快解最快，不需要模型账号；Codex 蜂群适合难题，多个 Agent 并行竞速；Muteki 蜂群需要本机 Muteki 服务已启动。

          

        

        

          3
          

            在运行页看结果
            
“共享事实”记录已经确认的发现，“下一手”给可执行命令，“Flag 台账”区分候选和已验证。命令可以在下方 Kali 控制台直接执行。

          

        

      


      

        

          语料检索
          
搜 SQL 注入、tcache、RSA Coppersmith 等关键词；BM25 排序或 ripgrep 正则直搜，全部离线。

        

        

          变换台
          
Base64 / Hex / Morse / ROT / XOR / JWT / Brainfuck 等；先点“Magic 自动识别”最省事。

        

        

          设置与诊断
          
看语料、Kali、Codex、Muteki 是否就绪；Muteki 服务也在这里启动。

        

        

          运行记录
          
每次运行都保存在 studio/runs/，包括事实、命令和最终 brief。

        

      


      

        使用边界：只在你拥有或已获授权的题目 / 靶机上使用；flag 只有能追溯到真实执行输出或人工确认时才算已验证。
